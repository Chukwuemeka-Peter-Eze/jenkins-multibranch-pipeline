# Glossary

**Multibranch Pipeline** — Jenkins pipeline model capable of discovering and managing pipelines for multiple repository branches.

**Branch Discovery** — Process through which Jenkins identifies repository branches.

**Jenkinsfile** — Pipeline definition stored as code.

**Webhook** — HTTP-based event notification from a source-control system.

**Credential** — Authentication information managed securely by Jenkins.

**Pipeline Parameter** — Input supplied to a pipeline execution.

**Application Version** — Identifier representing a specific application release state.

**Docker Image Tag** — Identifier used to distinguish container image versions.

**Recursive Trigger** — Unintended pipeline execution caused by an automated action from a previous pipeline execution.

**Pipeline-as-Code** — Defining CI/CD workflows in version-controlled source files.

**CI/CD** — Continuous Integration and Continuous Delivery/Deployment.

**Artifact** — Build output produced for distribution or deployment.
