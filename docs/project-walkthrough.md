# Project Walkthrough

## Phase 1 — Multibranch Pipeline

Configure Jenkins to discover the repository branches.

## Phase 2 — Branch Logic

Implement branch-specific behavior within the Jenkinsfile.

## Phase 3 — Credentials

Configure the credentials required by the pipeline.

## Phase 4 — Webhooks

Connect repository events to Jenkins.

## Phase 5 — Versioning

Implement application version management.

## Phase 6 — Docker

Build the appropriately versioned application image.

## Phase 7 — Git Commit

Commit the version change from Jenkins.

## Phase 8 — Recursive Trigger Protection

Ensure the Jenkins-generated commit does not unintentionally restart the same pipeline.

## Phase 9 — Full Validation

Execute the complete workflow and capture evidence.
