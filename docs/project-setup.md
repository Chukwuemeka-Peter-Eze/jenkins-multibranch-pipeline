# Project Setup

## Prerequisites

* Jenkins
* Git
* GitHub repository
* Maven
* Docker
* Jenkins credentials
* Webhook access

```text
Repository
   ↓

   ↓
Credentials
   ↓

   ↓
Webhook
   ↓
Pipeline
   ↓
Versioning
   ↓
Docker
```
