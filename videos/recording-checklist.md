# Recording Checklist

## Before Recording

* [ ] Jenkins dashboard clean
* [ ] Browser zoom appropriate
* [ ] Terminal font readable
* [ ] No credentials visible
* [ ] No API keys visible
* [ ] No personal secrets visible
* [ ] Repository prepared
* [ ] Architecture diagram ready
* [ ] Pipeline ready
* [ ] Webhook ready
* [ ] Test branch ready

## During Recording

* [ ] Explain architecture first
* [ ] Demonstrate Multibranch behavior
* [ ] Demonstrate credentials safely
* [ ] Demonstrate webhook
* [ ] Demonstrate versioning
* [ ] Demonstrate Docker version
* [ ] Demonstrate Git commit
* [ ] Explain recursive-trigger protection

## After Recording

* [ ] Review video
* [ ] Verify no secrets were captured
* [ ] Confirm commands are readable
* [ ] Confirm pipeline output is visible
* [ ] Edit unnecessary waiting time
* [ ] Add final thumbnail
